# Git Cheat Sheet

|        Command         |                                  Description                                   |
| :--------------------: | :----------------------------------------------------------------------------: |
|        git init        |                             Initialize a new repo                              |
|    git clone <url>     |                                  Clone a repo                                  |
|   git add <filename>   |                        Stages this specific <filename>                         |
|       git add .        |                     Stages all current directory(downward)                     |
|       git add -A       |                  Stages everything from the current directory                  |
|       git status       |                                What has changed                                |
| git commit -m "<msg>"  |                        Commit on the current stage area                        |
| git commit -am "<msg>" | Automatically stages and commits all changes to files that Git already tracks. |
